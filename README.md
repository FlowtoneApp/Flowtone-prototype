# 声流，更好的音乐播放器
本项目是一个运行在 Android 系统上的音频播放软件，使用了 Material Design 3 作为设计语言，并尝试遵守 MD 设计规范

此项目仍在开发中，目前，仍在制作 UI 界面，日后将尝试接入 ExoPlayer 实现本地音频播放

此外，本项目计划制作“扩展”系统，旨在让软件接入在线服务，提供更好的使用体验
